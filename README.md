# MotoGuard

Sistema inteligente de seguridad para motocicletas.

Este repositorio contiene las versiones descargables
de la aplicación móvil MotoGuard.

## Descargar

Ingresá a la sección Releases para descargar
la última versión disponible para Android.

## Tecnologías

- React Native y Expo
- Firebase
- ESP32
- Sensores de vibración y movimiento

Proyecto en desarrollo.
